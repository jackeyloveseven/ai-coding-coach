分档

每次任务先分档：用两个问题决定该教多少

出错时后果有多隐蔽？亲手做一遍对判断力的价值有多大？拿不准时按黄档处理——宁可少教，也不在该打断的地方打断。

绿：放手
样板代码、argparse、日志、画图、shell 命令
直接做好，不加教学。学 API 语法、调 matplotlib 样式不增值，说教只会烦人。
黄：读懂
数据处理、训练循环、loss 实现、评估代码、超参改动
做完，附一个 6 行以内的「读懂检查点」：关键行为什么这么写、这段最可能悄悄错在哪、你能直接跑的验证方式。
红：亲手
attention / loss / 采样 / 优化器、方案设计、实验设计、读数、决定下一步
进入教练模式：先给脚手架，请你出手，再对照差异。决定权始终在你。

动机

四个失败模式

写代码在快速贬值，「判断」没有。下面四条是初级算法工程师在 AI 时代最常摔的坑——这个仓库里的每一样东西，都对着其中一条。

#1

能跑通，但结果悄悄是错的

最贵的 bug 不是报错，是能跑、指标也出来了、但其实错了。训练集和验证集顺序反了、指标算在了增强后的数据上、loss 累加时样本数没除对——这些都不崩，只会让你在错误的结论上再走三个月。

解法：黄档的「静默风险」专门盯这个，附一段你能直接跑的验证方式。

#2

loss 降了，但不知道那是不是真的学到东西

loss 一路降、指标涨了 3 个点——是改动有效，还是数据泄露、随机波动、reward hacking？结果出来之后再决定「涨多少算有效」，几乎总会得出「有效」的结论。

解法：事前记录（假设 / 对照 / 变量 / 判据 / 止损 / 预测）跑之前写完，读数时判据就摆在指标正上方。

#3

实验跑完了，下一步全靠感觉

继续还是停、换哪个参数、要不要加卡——这些决定没人替你做。AI 也不知道你的业务和数据，给不出可靠建议。

解法：红档不给答案，给脚手架，请你先说出「我打算下一步做什么、为什么」，再对照。

#4

我越来越不做「判断」这个动作了

代码几乎都由 agent 写，你审得越来越少。判断力不是被 AI 拿走的，是你不再练习而退化的——它不会因为 AI 变强而消失，反而因为 AI 产出变多而更值钱。

解法：掌握度台账按 1 / 3 / 7 / 16 / 35 天间隔复习，稳了的降一档、反复出错的升一档。想主动练就敲 /coach-drill。

贯穿全篇的一条判断：分工的边界不在「谁写代码」，而在「谁对结果负责」。

常驻成本

两个 skill，按「谁能触发」分工

装两个 skill，但真正的内容只在你用到时才加载。数字是 claude plugin details 自己算的。

skill触发方式干什么常驻成本
ai-coding-coach 自动（model-invoked） 常驻纪律。你写代码、调 bug、看日志时自动生效，顺手把你拉进判断。 ~240 token
/coach-drill 只有你手打（user-invoked） 显式编排。想主动练 15–25 分钟时敲它，从台账挑到期的主题带你练。 ~70 token

两个加起来，每次会话只多占 约 310 token。真正的内容（3.5k / 1.1k）只在你用到时才加载，所以常驻不构成上下文负担——一条 CLAUDE.md 规则、一个 MCP server 的描述，往往比这还贵。那 70 token 是 /coach-drill 的描述：disable-model-invocation 只关掉了自动触发，描述仍留在技能列表里，好让你知道有这扇门。

配套工具

exptool：把事前记录接到训练日志上

光有一条纪律没用，得让它在正确的时刻出现在你眼前。exp 读实验目录下的 PLAN.md，把判据印在指标正上方。

$ exp status demo-sft
实验: demo-sft
机器: local
目录: ./examples/demo-sft
方法: sft

健康检查
  tmux train-demo: 在
  日志最后更新: 2 分钟前（train.log）

事前记录
  判据: 用固定 dev 集上的 eval loss 判断，比 baseline 低 0.02 以上才算有效
  预测: 我觉得 eval loss 会低 0.01~0.03，把握中
  （全文: exp plan demo-sft）

进度
  step  4200/8000    loss 0.84    eval loss 0.91
  读数看趋势，不看单步
命令干什么
exp list登记了哪些实验，哪些还在跑
exp status进度、指标趋势、健康检查，外加事前记录的判据
exp plan没有 PLAN.md 就按六项生成模板，有就打印全文
exp report生成一份自包含的 HTML 报告：曲线 + 判据参考线 + 健康检查

每条命令执行前都会打印它背后真正跑的命令（灰色的 + ssh ...）。复制下来自己改着用，熟了以后不用这个工具也能干。它是脱敏的通用版：主机名、共享盘路径、奖励服务地址全部走配置文件，本地就能试，不需要集群。
